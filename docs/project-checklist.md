# Project startup checklist

Use this checklist when starting a new project from this architecture shell.
For EM2 it was completed in M0; see `docs/milestones/M0.md`.

## 1. Architecture initialization

- [x] Define the sealed core contract.
- [x] Define the registry and bootstrap model.
- [x] Define adapter and plugin boundaries.
- [x] Define the module list.
- [x] Define the core invariants.

## 2. Project structure

- [x] Create the root project contract file.
- [x] Create the agent registry.
- [x] Create the Codex guidance file.
- [x] Create the docs folder.
- [x] Create the scripts folder.

## 3. Milestone setup

- [x] Define the milestone list.
- [x] Add the milestone checklist.
- [x] Map each subsystem to one milestone.
- [x] Define milestone acceptance criteria.

## 4. Issue and label model

- [x] Define project labels.
- [x] Define milestone labels.
- [x] Define priority labels.
- [x] Define quality labels.
- [x] Add the issue template.

## 5. QA and validation

- [x] Add unit-test requirements.
- [x] Add contract-test requirements.
- [x] Add smoke-test requirements.
- [x] Add regression-test requirements.
- [x] Add milestone gate validation.

## 6. Coordination layer

- [x] Add orchestrator definition.
- [x] Add validator definition.
- [x] Add project manifest generator.
- [x] Add orchestrator script.
- [x] Add validator script.

## 7. Final gate

- [x] Run project validation.
- [x] Run manifest generation.
- [x] Ensure all required docs exist.
- [x] Confirm a new repo can start from this shell.

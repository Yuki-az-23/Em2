request id onto shared problem values, a data race under concurrent requests that could hand one caller
another caller's request id. `TestConcurrentProblemsDoNotShareState` reproduces it (3 races reported

## Differences from the blueprint

- Module roles are created by `em2 migrate` and entered with `SET LOCAL ROLE` per transaction, instead of
  a hand-maintained `db/roles.sql`. One connection pool serves every module.
- Agents live in the identity module (blueprint B2 layout), not a separate `agents` module.
- The direct dependency rule is "two direct requirements". `pgx` and `x/crypto` bring small indirect
  modules (`puddle`, `pgpassfile`, `pgservicefile`, `x/sync`, `x/sys`, `x/text`).

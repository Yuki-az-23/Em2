# ADR-008: Relicense to AGPL-3.0-or-later

Status: accepted (M0)

## Decision
The project moves from MIT to the GNU Affero General Public License, version 3 or later. All code in
this repository from M0 onward is under that license. The legacy code in history keeps the MIT terms
it was published under.

## Consequences
Anyone running a modified EM2 as a network service must offer its source to that service's users,
which fits a tool meant to protect people from opaque content systems.

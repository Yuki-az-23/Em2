# Docs Maintainer

## Mission
Keep project documentation aligned with code and milestones.

## Responsibilities
- maintain architecture docs
- update runbooks and onboarding
- keep milestone docs current
- preserve repo narrative quality

## Rules
- Docs must reflect reality
- Keep milestone and project descriptions synchronized
- Keep onboarding actionable and concise

## In EM2
- Owns `docs/`, `agent/`, `CLAUDE.md`, `README.md` and the milestone summaries in `docs/milestones/`.
- Docs must match the code; the old `Docs/` tree is legacy and not a source of truth.
